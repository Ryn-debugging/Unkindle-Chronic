# Unkindle-Chronic

Ini adalah project game visual novel yang dibuat menggunakan engine **Ren'Py**.

## Cara Memainkan
1. Download rilisan game di bagian Releases (jika sudah ada).
2. Ekstrak file zip.
3. Jalankan file `.exe` atau `.app` sesuai sistem operasi Anda.
